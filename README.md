# 나의 다이어리 📖

일정 · 가계부 · 카드 · 메모 · 일기 · 꿈을 한곳에 모은 **모바일 우선 개인 다이어리 웹앱(PWA)** 입니다.
서버 없이 이 기기의 브라우저(`localStorage`)에만 저장되고, 홈 화면에 추가해서 앱처럼 쓸 수 있어요.

## 여는 방법

1. **인터넷에 올려서 쓰기 (권장)**
   GitHub Pages · Vercel · Netlify 같은 무료 정적 호스팅에 이 폴더를 그대로 올리면 끝이에요.
   주소가 생기면 안드로이드 크롬에서 열고 → 오른쪽 위 `⋮` → **홈 화면에 추가**.
2. **이 컴퓨터에서 미리 보기**
   ```bash
   cd my-diary-app
   python3 -m http.server 8000
   # 브라우저에서 http://localhost:8000
   ```
   (`index.html`을 파일로 바로 열어도 대부분 동작하지만, 홈 화면 추가·오프라인 기능은 주소가 있어야 해요.)

## 화면 구성

| 탭 | 내용 |
|---|---|
| 📅 **일정** | **다이어리**(기본)와 **달력** 전환. 다이어리는 종이 다이어리 한 장처럼 영문 요일·월·날짜 머리글 + 줄노트 + `TO DO:` 로 하루를 적고, 좌우 스와이프·`◀ 이전 날 / 다음 날 ▶`로 페이지를 넘겨요. 달력은 월간 캘린더 + 날짜별 할 일(완료 체크 · 중요 ★ · 시간/순번). 달력 칸에는 일정 제목이 **색 막대로 바로 보이고**(기본값), 넘치면 `+N` 으로 표시돼요. 위쪽 **검색창**에서 낱말로 일정·다이어리·메모·일기를 찾을 수 있어요 |
| 💰 **가계부** | **일반 가계부**와 **재테크 가계부**를 완전히 분리. 각 장부 안에서 **내역** / **📊 통계** 전환 — 통계는 수입·지출 각각의 **원형 그래프 + % 배지 + 카테고리별 금액 목록** |
| 💳 **카드** | 카드사·카드명·카드 색, **목표 실적 대비 채운 실적(진행률 바 + 남은 금액)**, 결제일·만기일, 혜택·주의사항 메모. 혜택 캡처를 여러 장 붙이고 누르면 **라이트박스**로 크게 봐요 |
| 📝 **메모** | **포스트잇**(색 5가지·맨 위 고정)과 **공책**(줄노트 한 페이지에 길게 쓰고 좌우로 넘기는 메모장) 전환. 카드를 누르면 그 메모가 공책으로 펼쳐져요 |
| 📖 **일기** | 날짜별 일기, 기분 이모지 5가지, 줄노트 본문, 자동 저장. **4자리 비밀번호 · 지문(생체인증) 잠금**을 켤 수 있어요 |
| ✨ **꿈** | 사진 + 제목 + 다짐 글 + 목표 시기 카드. 맨 위에 **오늘의 꿈**이 매일 한 장씩 바뀌어 보여요 |
| ⚙️ **설정** | 테마 색상, **일기 잠금(비밀번호·지문)**, JSON 백업 내보내기 / 불러오기, 샘플·전체 데이터 지우기 |

## 🎨 테마 색상

- 오른쪽 위 **팔레트 버튼** 또는 **설정 → 테마 색상**에서 바꿉니다.
- 프리셋 6종: 크림·테라코타(기본) · 벚꽃 핑크 · 바질 그린 · 라벤더 · 스카이 블루 · 모래·골드
- **직접 고르기**: 색상 고르개(`<input type="color">`)에서 원하는 색을 고르면 그 색으로 포인트가 바뀌고 종이 바탕도 살짝 물듭니다.
- 고르는 즉시 하단 탭·버튼·달력·다이어리·그래프 포인트까지 앱 전체에 적용되고, `localStorage`와 JSON 백업에 함께 저장돼요.

## 🗓 달력 막대 보기 · 검색

- 달력 칸마다 일정 제목이 **색 막대**로 보여요. 제목에 맞춰 색이 정해집니다 —
  생리(분홍) · 병원·약(주황) · 카드·은행·실적(파랑) · 장보기·마트(초록) · 학교·학원(보라) · 여행·이사(청록) · 생일·선물(노랑).
  제목에 그런 낱말이 없으면 같은 제목끼리 늘 같은 색으로 보여요.
- 하루에 다 못 담으면 `+4` 처럼 남은 개수를 보여 주고, 그 날짜를 누르면 아래에 그날 일정이 전부 나옵니다.
- 한 칸에 보이는 막대 수는 화면 폭에 따라 달라요: 폰 3개 → 넓은 폰 4~5개 → 태블릿·폴드 6개.
- 오른쪽 위 `▤ / •••` 버튼으로 **막대 보기 ↔ 점 보기**를 바꿀 수 있어요(기본은 막대 보기).
- 일정을 고칠 때 **달력 막대 색**을 직접 고를 수도 있어요(그냥 두면 ‘자동’).
- 위쪽 **검색창**에 `생리`, `치과`, `장보기` 처럼 적으면 일정·다이어리(날짜 메모)·메모·일기를 **최신순**으로 모아 보여 줍니다.
  결과를 누르면 그 날짜 화면으로 바로 이동해요. 잠긴 일기는 검색 결과에도 나오지 않아요.

## 🔒 일기 잠금 (비밀번호 4자리 · 지문)

- **설정 → 일기 잠금**에서 4자리 숫자를 정하면 잠금이 켜져요. (`기본값: 꺼짐`)
- 잠금이 켜져 있으면 **일기 탭**을 열 때마다 숫자 키패드가 먼저 뜨고, 맞는 비밀번호를 눌러야 내용이 보입니다.
- **지문(생체인증)** 을 함께 등록해 두면 잠금 화면에서 `👆 지문으로 열기` 한 번으로 열려요.
  (HTTPS 주소 + 기기 지문을 지원하는 브라우저에서만 동작하고, 안 되면 PIN으로 열 수 있어요.)
- 잠금이 풀린 상태에서도 일기 화면 위 `🔒` 버튼으로 바로 다시 잠글 수 있어요.
  앱을 다시 열거나, 다른 앱에 다녀온 시간이 3분을 넘으면 다시 잠깁니다.
- 잠금이 켜져 있으면 **백업 내보내기**도 비밀번호를 확인한 뒤에 됩니다.
- 이 잠금은 화면을 가리는 잠금이에요. 브라우저 저장소의 일기 내용 자체를 암호화하지는 않으니
  폰을 다른 사람에게 맡길 때는 참고해 주세요. 비밀번호를 잊으면 앱에서 일기를 열 수 없습니다.

## ✍️ 다이어리(종이) 사용법

- 하루에 한 장. 위쪽에 `WEEK 47` · `Friday` · `NOVEMBER 20` 이 종이 다이어리처럼 들어갑니다.
- 줄노트에 적으면 **0.4초 뒤 자동 저장**(탭을 옮기거나 페이지를 넘길 때도 저장).
- 아래 `TO DO:` 는 그날의 일정과 같은 목록이라, 여기서 체크하면 달력에도 바로 반영돼요.
- 좌우로 쓸어넘기거나 `◀ 이전 날 / 다음 날 ▶` 로 하루씩 넘어가고, 넘길 때 페이지가 도는 애니메이션이 붙습니다. 데스크톱에서는 ←, → 키도 돼요.
- `오늘` 버튼으로 오늘 페이지로 돌아옵니다.

## 💰 두 장부 카테고리

- **일반 가계부** — 지출: 식비 · 장보기 · 카페 · 교통 · 생활 · 의료 · 교육 · 기타 / 수입: 급여 · 부수입 · 중고거래 · 환급 · 용돈 · 기타
- **재테크 가계부** — 수입: 카드테크 · 포인트&현금 · 주식 · 투자 · 공모주 · 이자/배당 · 기타 / 지출: 수수료 · 세금 · 손실 · 기타
- `＋ 직접` 으로 넣은 카테고리는 그 장부에 계속 남아요.
- 예전 버전에서 `재테크` 구분으로 넣어 둔 내역은 앱을 열 때 재테크 가계부로 자동으로 옮겨집니다.

## 🖼 사진은 이렇게 저장돼요

- 사진을 고르면 앱이 **자동으로 줄여서** 저장합니다. (꿈 사진 1000px, 카드 혜택 캡처 1400px · JPEG)
- 저장된 사진은 **JSON 백업 파일에도 그대로 담겨요.** 폰을 바꿔도 사진까지 함께 옮겨집니다.
- 사진은 이 기기의 브라우저 저장소에만 들어가고 서버로 보내지 않아요.
- 저장 공간이 거의 차면(약 4.5MB) 알림이 떠요. 오래된 사진을 정리하거나 백업 후 지워 주세요.

## 데이터 & 백업

- 입력하는 즉시 `localStorage`에 자동 저장됩니다.
- 폰을 바꾸기 전에는 **설정 → JSON으로 백업 내보내기**로 파일을 받아 두세요.
- 새 폰에서 앱을 열고 **설정 → 백업 불러오기**로 그 파일을 고르면 됩니다 (합치기 / 덮어쓰기 선택).
- 백업 파일에는 일정 · 가계부(두 장부 모두) · 카드(혜택 캡처 포함) · 메모 · 다이어리 · 일기 · 꿈(사진 포함) · 테마 색이 모두 들어 있습니다.
- 일기 잠금이 켜져 있으면 백업을 내보내기 전에 4자리 비밀번호를 확인합니다.

## 폴더 구조 (새 탭 추가하기)

```
my-diary-app/
├─ index.html            # 화면 틀 + 스크립트 목록
├─ manifest.json         # 홈 화면 추가용 정보
├─ sw.js                 # 오프라인 캐시
├─ css/app.css           # 전체 디자인
├─ js/
│  ├─ store.js           # 저장·백업·샘플 데이터
│  ├─ ui.js              # 날짜/금액/토스트/입력 시트/사진 줄이기
│  ├─ theme.js           # 테마 색(프리셋·직접 고르기)
│  ├─ lock.js            # 일기 잠금(4자리 PIN · 지문 WebAuthn)
│  ├─ app.js             # 탭 이동, 시작, 떠 있는 ＋ 버튼
│  └─ tabs/              # ← 화면(탭) 하나당 파일 하나
│     ├─ schedule.js     # 다이어리 + 달력
│     ├─ finance.js      # 두 장부 + 통계
│     ├─ card.js         # 카드 · 라이트박스
│     ├─ memo.js         # 포스트잇 + 공책
│     ├─ diary.js
│     ├─ dream.js
│     └─ settings.js
└─ icons/
```

새 탭(예: 운동 기록)을 붙이는 방법:

1. `js/tabs/exercise.js` 파일을 만들고 아래처럼 등록합니다.

   ```js
   (function () {
     const T = (window.Tabs = window.Tabs || {});
     T.exercise = {
       id: 'exercise', label: '운동', title: '운동',
       icon: '<svg …></svg>',
       render: function (root) {
         root.innerHTML = '<div class="empty">운동 기록 화면</div>';
       }
     };
   })();
   ```

2. `index.html` 의 스크립트 목록과 `js/app.js` 의 `ORDER` 배열에 `exercise`를 더합니다.
   (하단 탭이 7개를 넘으면 좁은 화면에서 글자가 작아지니, 그때는 탭 이름을 더 줄여 주세요.)
