# 나의 다이어리 📖

일정 · 가계부 · 카드 · 메모 · 일기 · 꿈 · 바로가기를 한곳에 모은 **모바일 우선 개인 다이어리 웹앱(PWA)** 입니다.
서버 없이 이 기기의 브라우저(`localStorage`)에만 저장되고, 홈 화면에 추가해서 앱처럼 쓸 수 있어요.

## 여는 방법

1. **인터넷에 올려서 쓰기 (권장)**
   GitHub Pages · Vercel · Netlify 같은 무료 정적 호스팅에 이 폴더를 그대로 올리면 끝이에요.
   주소가 생기면 안드로이드 크롬에서 열고 → 오른쪽 위 `⋮` → **홈 화면에 추가**.
2. **이 컴퓨터에서 미리 보기**
   ```bash
   cd my-diary-app
   python3 -m http.server 8000
   # 브라우저에서 http://localhost:8000
   ```
   (`index.html`을 파일로 바로 열어도 대부분 동작하지만, 홈 화면 추가·오프라인 기능은 주소가 있어야 해요.)

## 화면 구성

| 탭 | 내용 |
|---|---|
| 📅 **일정** | **다이어리**(기본)와 **달력** 전환. 다이어리는 종이 다이어리 한 장처럼 영문 요일·월·날짜 머리글 + 줄노트 + `TO DO:` 로 하루를 적고, 좌우 스와이프·`◀ 이전 날 / 다음 날 ▶`로 페이지를 넘겨요. 달력은 월간 캘린더 + 날짜별 할 일(완료 체크 · 중요 ★ · 시간/순번). 달력 칸에는 일정 제목이 **색 막대로 바로 보이고**(기본값), 넘치면 `+N` 으로 표시돼요. 위쪽 **검색창**에서 낱말로 일정·다이어리·메모·일기를 찾을 수 있어요 |
| 💰 **가계부** | **일반 가계부**와 **재테크 가계부**를 완전히 분리. 각 장부 안에서 **내역** / **📊 통계** 전환 — 통계는 수입·지출 각각의 **원형 그래프 + % 배지 + 카테고리별 금액 목록**(카테고리를 누르면 그 달의 상세 내역). 일반 가계부에는 **🔄 고정 수입/지출**(매달 자동 기록)과 **🗂 카테고리 관리**가 있어요 |
| 💳 **카드** | 카드사·카드명·카드 색, **목표 실적 대비 채운 실적(진행률 바 + 남은 금액)**, 결제일·만기일, 혜택·주의사항 메모. 혜택 캡처를 여러 장 붙이고 누르면 **라이트박스**로 크게 봐요 |
| 📝 **메모** | **포스트잇**(색 5가지·맨 위 고정)과 **공책**(줄노트 한 페이지에 길게 쓰고 좌우로 넘기는 메모장) 전환. 카드를 누르면 그 메모가 공책으로 펼쳐져요. 두 곳 모두 **글자 서식**(굵게·밑줄·취소선·크기 4단계·형광펜 4색·글자색)을 쓸 수 있어요 |
| 📖 **일기** | 날짜별 일기, 기분 이모지 5가지, 줄노트 본문, 자동 저장. **사진·동영상 첨부**(눌러서 크게 보기), **4자리 비밀번호 · 지문(생체인증) 잠금**을 켤 수 있어요 |
| ✨ **꿈** | 사진 + 제목 + 다짐 글 + 목표 시기 카드. 맨 위에 **오늘의 꿈**이 매일 한 장씩 바뀌어 보여요 |
| 🔗 **바로가기** | 자주 가는 사이트를 **둥근 아이콘 격자(폰 3열 · 넓은 화면 4열)** 로 모아 둡니다. 이름·주소·이모지·색·묶음(분류)·메모를 넣어 **추가·수정·삭제·순서 바꾸기**가 되고, 아이콘을 누르면 새 탭에서 열려요 |
| ⚙️ **설정** | 테마 색상, **일기 잠금(비밀번호·지문)**, JSON 백업 내보내기 / 불러오기, 샘플·전체 데이터 지우기 |

## 🎨 테마 색상

- 오른쪽 위 **팔레트 버튼** 또는 **설정 → 테마 색상**에서 바꿉니다.
- 프리셋 6종: 크림·테라코타(기본) · 벚꽃 핑크 · 바질 그린 · 라벤더 · 스카이 블루 · 모래·골드
- **직접 고르기**: 색상 고르개(`<input type="color">`)에서 원하는 색을 고르면 그 색으로 포인트가 바뀌고 종이 바탕도 살짝 물듭니다.
- 고르는 즉시 하단 탭·버튼·달력·다이어리·그래프 포인트까지 앱 전체에 적용되고, `localStorage`와 JSON 백업에 함께 저장돼요.
- 색은 **선명한 톤**으로 맞춰져 있어요(2026-11 색감 개선). 달력 막대(칩)·오늘/선택한 날·카테고리 뱃지·수입/지출 금액·메모 포스트잇·그래프가 한눈에 구분됩니다.
- 예전 옅은 테마 색이 저장돼 있어도 앱을 열면 새 선명한 색으로 보입니다(저장된 데이터는 그대로).

## 🗓 달력 막대 보기 · 검색

- 달력 칸마다 일정 제목이 **색 막대**로 보여요. 색은 다섯 가지로만 나뉩니다 —
  **① 생일·생신(생일·생신·🎂)** 은 **노랑**,
  **② 생리 일정(생리·생리시작·생리통·월경·PMS)** 은 **진한 초록**(짙은 초록 바탕에 흰 글자),
  **③ 아이 일정(종원·아들·학교·방학·급식·성교육·WCA·큐브·대회)** 은 **연한 초록**,
  **④ 병원·검진·치과·한의원·약국·접종처럼 개인 병원 예약** 은 **주황**,
  **⑤ 카드 납부·대출이자·자동이체·보험료·지로·도시가스·국민연금·정기 후원처럼 정해진 날 돈이 나가는 납부·이체** 는 **보라**,
  **⑥ 그 밖의 일정** 은 **기본 베이지**예요.
  순서는 생일 → 생리 → 아이 → 병원 → 납부·이체 → 기본이고, 아이 일정이 병원이어도(예: 종원 교정 치과) 연한 초록이 우선이며, 아이 생일은 생일이라 노랑입니다. `생일`·`병원`·`치과`·`납부`·`자동이체`·`카드결제`·`대출금`·`이자`처럼 제목에 적은 낱말로 찾으며, `카드발급`·`가입`·`해지`·`실적`·`한도`처럼 납부가 아닌 줄은 보라로 칠하지 않아요.
- 하루에 다 못 담으면 `+4` 처럼 남은 개수를 보여 주고, 그 날짜를 누르면 아래에 그날 일정이 전부 나옵니다.
- 한 칸에 보이는 막대 수는 화면 폭에 따라 달라요: 폰 3개 → 넓은 폰 4~5개 → 태블릿·폴드 6개.
- 오른쪽 위 `▤ / •••` 버튼으로 **막대 보기 ↔ 점 보기**를 바꿀 수 있어요(기본은 막대 보기).
- 일정을 고칠 때 **달력 막대 색**을 직접 고를 수도 있어요(그냥 두면 위 규칙대로 ‘자동’, 고르면 그 색이 우선).
  색은 **로즈·코랄·파랑·초록·보라·청록·골드·베이지 여덟 계열 × 연한 톤·진한 톤** = 동그라미 16개이고, 윗줄이 연한 톤, 아랫줄이 같은 색의 진한 톤이에요. 진한 톤은 흰 글자로 보여서 멀리서도 잘 띕니다.
- 위쪽 **검색창**에 `생리`, `치과`, `장보기` 처럼 적으면 일정·다이어리(날짜 메모)·메모·일기를 **최신순**으로 모아 보여 줍니다.
  결과를 누르면 그 날짜 화면으로 바로 이동해요. 잠긴 일기는 검색 결과에도 나오지 않아요.

## 📷 일기 사진·동영상

- 일기 종이 아래 **`📷 사진·동영상 추가`** 로 그날의 사진과 동영상을 여러 개 붙일 수 있어요.
- 붙인 사진·동영상은 종이 안에 격자로 보이고, 누르면 **크게 보기**(여러 개면 좌우로 넘기기, 동영상은 재생)가 열립니다.
- 각 칸 오른쪽 위 `×` 로 하나씩 지울 수 있고, 일기를 지우면 함께 지워집니다.
- 사진은 붙일 때 긴 변 **1400px JPEG**로 줄여 저장하고, 동영상은 원본 그대로 저장해요.
- **저장 위치**: 글은 `localStorage`, 사진·동영상 파일은 브라우저의 **IndexedDB**(`myDiaryMedia`)에 이 기기에만 저장됩니다. 어디로도 보내지 않아요.
- **백업(JSON)에는 사진·동영상이 들어가지 않아요** — 백업 파일에는 날짜·글·기분·첨부 목록만 담깁니다. 폰을 바꾸면 사진·동영상은 옮겨지지 않으니, 꼭 남길 사진은 앨범에도 따로 보관해 주세요.

## 🔒 일기 잠금 (비밀번호 4자리 · 지문)

- **설정 → 일기 잠금**에서 4자리 숫자를 정하면 잠금이 켜져요. (`기본값: 꺼짐`)
- 잠금이 켜져 있으면 **일기 탭**을 열 때마다 숫자 키패드가 먼저 뜨고, 맞는 비밀번호를 눌러야 내용이 보입니다.
- **지문(생체인증)** 을 함께 등록해 두면 잠금 화면에서 `👆 지문으로 열기` 한 번으로 열려요.
  (HTTPS 주소 + 기기 지문을 지원하는 브라우저에서만 동작하고, 안 되면 PIN으로 열 수 있어요.)
- 잠금이 풀린 상태에서도 일기 화면 위 `🔒` 버튼으로 바로 다시 잠글 수 있어요.
  앱을 다시 열거나, 다른 앱에 다녀온 시간이 3분을 넘으면 다시 잠깁니다.
- 잠금이 켜져 있으면 **백업 내보내기**도 비밀번호를 확인한 뒤에 됩니다.
- 이 잠금은 화면을 가리는 잠금이에요. 브라우저 저장소의 일기 내용 자체를 암호화하지는 않으니
  폰을 다른 사람에게 맡길 때는 참고해 주세요. 비밀번호를 잊으면 앱에서 일기를 열 수 없습니다.

## 🔗 바로가기 (자주 가는 사이트)

- 아래 **🔗 바로가기** 탭에서 자주 가는 사이트를 스마트폰 폴더처럼 모아 둡니다.
- `＋ 추가`(또는 오른쪽 아래 `＋ 바로가기`)를 누르고 **이름 · 주소 · 아이콘(이모지 또는 이름 첫 글자) · 색 · 묶음(선택) · 메모(선택)** 를 넣으면 돼요.
  주소는 `naver.com` 처럼만 적어도 `https://` 가 자동으로 붙습니다.
- **고치기 / 지우기** — 오른쪽 위 `편집` 을 누르거나 아이콘을 **길게 누르면** 편집 모드가 되고, 각 아이콘 위에 `✕`(삭제) · `✎`(수정) 버튼이 뜹니다.
  편집 모드에서 아이콘을 누르면 수정 창이 열려 **순서(◀ 앞으로 / 뒤로 ▶)** 도 바꿀 수 있어요.
- **묶음**에 같은 이름(예: `쇼핑`, `금융`)을 적으면 그끼리 모여 작은 제목 아래 정리됩니다. 비워 두면 맨 위 한 줄에 모여요.
- 아이콘을 누르면 `window.open(..., '_blank', 'noopener')` 로 **새 탭**에서 열립니다(앱 화면은 그대로 남아요).
- 목록은 **이 폰의 브라우저 저장소에만** 저장되고 어디로도 보내지 않습니다. 즐겨찾기 목록이 공개 저장소에 들어가지 않도록 기본 예시는 비어 있어요.

## ✍️ 다이어리(종이) 사용법

- 하루에 한 장. 위쪽에 `WEEK 47` · `Friday` · `NOVEMBER 20` 이 종이 다이어리처럼 들어갑니다.
- 줄노트에 적으면 **0.4초 뒤 자동 저장**(탭을 옮기거나 페이지를 넘길 때도 저장).
- 아래 `TO DO:` 는 그날의 일정과 같은 목록이라, 여기서 체크하면 달력에도 바로 반영돼요.
- 좌우로 쓸어넘기거나 `◀ 이전 날 / 다음 날 ▶` 로 하루씩 넘어가고, 넘길 때 페이지가 도는 애니메이션이 붙습니다. 데스크톱에서는 ←, → 키도 돼요.
- `오늘` 버튼으로 오늘 페이지로 돌아옵니다.

## ✏️ 메모 글자 서식 (굵게 · 크기 · 형광펜)

공책과 **메모 고치기** 창 위에 서식 도구가 있습니다. 두 곳 모두 같은 방식으로 써요.

- **B** 굵게 · **U** 밑줄 · **S** 취소선 — 글자를 골라 누르면 바로 적용되고, 다시 누르면 풀립니다. 커서만 둔 채 누르면 그다음 칠 글자부터 적용돼요.
- **가 크기 4단계** — 작게 · 보통 · 크게 · 아주 크게. 줄노트의 줄 간격은 그대로라 글자를 키워도 줄이 어긋나지 않아요.
- **형광펜 4색**(노랑 · 연두 · 분홍 · 하늘)과 `✕` 없애기, **글자색 4색**(검정 · 빨강 · 파랑 · 초록).
- **지우개** 버튼은 고른 글자의 서식(굵기·크기·색·형광·밑줄)을 한 번에 지웁니다.
- 포스트잇 카드에도 서식이 그대로 보이고, 태그 글자(`<b>` 같은 것)가 그대로 나오지 않아요.
- 저장할 때 서식(HTML)과 순수 글자를 함께 남겨서 검색 · 백업 · 예전 메모와 그대로 호환됩니다. 예전에 적어 둔 메모는 처음 열 때 줄바꿈 그대로 안전하게 바뀝니다.

- **재테크 가계부** — 수입: 카드테크 · 포인트&현금 · 주식 · 투자 · 공모주 · 이자/배당 · 기타 / 지출: 수수료 · 세금 · 손실 · 기타
- 일반 가계부 위 **`🗂 카테고리 관리`** 에서 지출·수입 카테고리를 **추가 · 이름 바꾸기 · 지우기** 할 수 있어요.
  - 이름을 고치면 지난 내역의 카테고리도 함께 바뀌고, 지워도 지난 내역은 그대로 남습니다.
  - 이모지를 앞에 붙이면(`🍕 간식`) 아이콘으로 보여요. `기본 카테고리로 되돌리기` 로 처음 목록으로 돌릴 수 있습니다.
- `＋ 직접` 으로 넣은 카테고리도 그 장부에 계속 남아요.
- 카테고리 목록은 **JSON 백업에 함께 담기고, 불러오기(합치기) 때 겹치지 않게 합쳐집니다.**
- 예전 버전에서 `재테크` 구분으로 넣어 둔 내역은 앱을 열 때 재테크 가계부로 자동으로 옮겨집니다.

## 📊 통계에서 카테고리 내역 보기

- **📊 통계** 화면의 카테고리 목록(`% · 카테고리명 · 금액`)에서 **행을 누르면** 그 카테고리 상세 내역 창이 열립니다. (일반 · 재테크 가계부 모두)
- 창 제목에 **`카테고리명 (2026.11.16 ~ 2026.12.15)`**(일반 가계부) 또는 **`카테고리명 (2026년 11월)`**(재테크 가계부), 그 아래 **`지출 · 총 12건 / 합계 4,442,810원`** 처럼 보고 있는 기간의 건수와 합계가 나와요.
- 안에는 그 기간 · 그 구분(수입/지출) · 그 카테고리의 내역이 **최신순**으로 나오고, 한 줄에 **날짜 · 항목명(메모) · `고정` 배지 · 결제수단 · 금액**이 보입니다.
- 내역을 **누르면 기존 수정/삭제 창**이 열려요. 저장하거나 지우면 **통계 숫자와 상세 내역이 함께 갱신**되고, 목록으로 돌아옵니다.
- 카테고리를 다 지워서 남은 내역이 없으면 창은 닫히고 통계 화면만 새로 그려집니다.

## 🔄 고정 수입/지출 (매달 자동 기록)

- 일반 가계부 위 **`🔄 고정 수입/지출`** 을 누르면 이번 달 기준 **`매월(수입: … 지출: …)`** 합계와 목록이 보여요.
- `＋ 추가` 로 **항목명 · 구분(수입/지출) · 금액 · 매월 며칠(1~31) · 카테고리 · 결제수단(기본 현금) · 활성 여부**를 넣습니다.
  - 31일처럼 없는 달은 그 달 **마지막 날**로 맞춰 기록해요.
- 목록에서 **누르면 수정**, 오른쪽 `켜짐 / 중지` 버튼으로 **그 달부터 멈추거나 다시 켤** 수 있고, 수정 창에서 지울 수 있어요.
- **자동 기록**: 앱을 열 때와 일반 가계부에 들어올 때, 이번 달 날짜가 지난 고정 항목을 **일반 가계부 내역에 자동으로 넣고 `고정` 배지**를 붙입니다.
  같은 달에 두 번 들어가지 않고(`YYYY-MM` 기준), 지운 항목은 다시 생기지 않아요. 이미 이번 달에 반영된 뒤라면 **`이번 달 미반영분 지금 반영`** 을 눌러도 중복되지 않습니다.
- 고정 내역은 **JSON 백업에 함께 담기고, 불러오기(합치기) 때 중복 없이 합쳐집니다.**

## 📅 일반 가계부 기간·예산 (시작일 자유 설정)

- 일반 가계부 위 **`🎯 예산·기간 설정`** 에서 **한 기간을 며칠부터 셀지** 고를 수 있어요. **1~28일 또는 그 달 말일** 중에서 고릅니다(기본값 1일).
  - 예를 들어 **16일**을 고르면 오늘(11/24) 기준 기간은 **`2026.11.16 ~ 2026.12.15`**. 16일 이전이면 `10.16 ~ 11.15`가 이번 기간이 돼요.
  - 상단에 실제 **시작일 ~ 종료일**이 표시되고, 옆의 **`‹` `›`** 로 지난 기간·다음 기간을 넘겨 볼 수 있어요.
  - 설정한 시작일은 **JSON 백업에 함께 담기고**, **재테크 가계부는 그대로 1일~말일(월 단위)** 로 동작합니다.
- 넘겨 보는 기간에 맞춰 **순수입·수입/지출 합계 · 내역 목록 · 📊 통계(원형 그래프) · 카테고리 상세 내역**이 모두 그 기간의 내역만으로 계산됩니다.
  - 두 달에 걸친 기간(예: 11.16~12.15)이면 11월분·12월분이 함께 나옵니다.
- **한 기간 예산**을 넣으면 요약 카드에 **진행률 바 · 남은 금액 · 사용률**이 나옵니다. 예산을 넘기면 빨간 바와 **`초과 00원`** 으로 바뀌어요. 예산을 비워 두면 내역만 보여드립니다.
- **고정 수입/지출**은 그 날짜가 지나면 일반 가계부 내역에 자동으로 들어가고, 두 달짜리 기간에서도 **11월분·12월분이 모두 빠짐없이** 보입니다. (규칙을 만들기 전 달이나 아직 오지 않은 날짜는 새로 만들지 않아요.)

## 🖼 사진은 이렇게 저장돼요

- 사진을 고르면 앱이 **자동으로 줄여서** 저장합니다. (꿈 사진 1000px, 카드 혜택 캡처 1400px · JPEG)
- 저장된 사진은 **JSON 백업 파일에도 그대로 담겨요.** 폰을 바꿔도 사진까지 함께 옮겨집니다.
- 사진은 이 기기의 브라우저 저장소에만 들어가고 서버로 보내지 않아요.
- 저장 공간이 거의 차면(약 4.5MB) 알림이 떠요. 오래된 사진을 정리하거나 백업 후 지워 주세요.

## 데이터 & 백업

- 입력하는 즉시 `localStorage`에 자동 저장됩니다.
- 폰을 바꾸기 전에는 **설정 → JSON으로 백업 내보내기**로 파일을 받아 두세요.
- 새 폰에서 앱을 열고 **설정 → 백업 불러오기**로 그 파일을 고르면 됩니다 (합치기 / 덮어쓰기 선택).
- 백업 파일에는 일정 · 가계부(두 장부 모두) · 카드(혜택 캡처 포함) · 메모 · 다이어리 · 일기 · 꿈(사진 포함) · **바로가기** · **고정 수입/지출** · **카테고리 목록** · 테마 색이 모두 들어 있습니다.
- 일기 잠금이 켜져 있으면 백업을 내보내기 전에 4자리 비밀번호를 확인합니다.

my-diary-app/
├─ index.html            # 화면 틀 + 스크립트 목록

├─ css/app.css           # 전체 디자인
├─ js/
│  ├─ store.js           # 저장·백업·샘플 데이터
│  ├─ ui.js              # 날짜/금액/토스트/입력 시트/사진 줄이기
│  ├─ theme.js           # 테마 색(프리셋·직접 고르기)
│  ├─ lock.js            # 일기 잠금(4자리 PIN · 지문 WebAuthn)
│  ├─ app.js             # 탭 이동, 시작, 떠 있는 ＋ 버튼
│  └─ tabs/              # ← 화면(탭) 하나당 파일 하나

새 탭(예: 운동 기록)을 붙이는 방법:

1. `js/tabs/exercise.js` 파일을 만들고 아래처럼 등록합니다.

   ```js
   (function () {
     const T = (window.Tabs = window.Tabs || {});
     T.exercise = {
       id: 'exercise', label: '운동', title: '운동',
       icon: '<svg …></svg>',
       render: function (root) {
         root.innerHTML = '<div class="empty">운동 기록 화면</div>';
       }
     };
   })();
   ```

2. `index.html` 의 스크립트 목록과 `js/app.js` 의 `ORDER` 배열에 `exercise`를 더합니다.
   (하단 탭은 지금 7칸이고, 320px 폭에서도 한 줄에 들어가도록 글자 크기를 자동으로 줄여 두었어요.
   8칸을 넘기면 탭 이름을 짧게 줄이는 것이 좋습니다.)
